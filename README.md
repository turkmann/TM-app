# TM — Turki Manger (PWA starter)

This is the first installable front-end foundation for TM. It is **not yet the complete product**.

## Included
- Mobile-first dark interface and bottom navigation
- Initial Dashboard and section placeholders based on the approved TM scope
- PWA manifest, app icon and service-worker cache for offline shell access
- Local draft creation for quick actions (stored only on the current device)

## Not included yet
- Supabase authentication, database, team permissions or cloud file storage
- Live Spotify / YouTube / Instagram / Apple Music / Anghami integrations
- Real analytics, finance workflows, full task/project CRUD, push notifications
- Production security, backup and conflict resolution

## Deploy
Upload the contents of this folder to a static host that serves HTTPS (for example Cloudflare Pages). Do not deploy secrets in this folder. After deployment, open the HTTPS URL in Safari on iPhone, tap Share, then Add to Home Screen.

## Important
Local drafts in this starter are not cloud-synced and can be lost if browser site data is cleared. Do not use this starter for confidential or business-critical records yet.
